# ระบบประวัติการฟังและรสนิยม (Taste)

เสริมระบบ Radio ([radio-design.md](radio-design.md)) ให้เพลงแนะนำอิงจากสิ่งที่ผู้ใช้ฟังจริง

## ข้อมูล
- `PlayRecord` (trackId, ชื่อ, ศิลปิน, เวลาที่ฟังจริง, ความยาว, เวลาเริ่ม, เริ่มจากการแนะนำหรือไม่)
- `ListenRecorder` นับเวลาฟังจริงด้วยนาฬิกา monotonic (หยุดชั่วคราวไม่นับ) → `ListeningHistory`
- เก็บเป็นไฟล์ JSON ในที่เก็บส่วนตัวของแอป (`filesDir/listening_history.json`) **ไม่ส่งออกนอกเครื่อง**
  เขียนแบบ atomic + debounce, จำกัดจำนวนรายการ (`MAX_HISTORY_ENTRIES`), ไฟล์เสียจะย้ายเป็น `.bad`
- ปิดการจดได้และล้างได้ในหน้าตั้งค่า

## การคำนวณ (`TasteProfileBuilder`)
- ฟังเกินสัดส่วน/เวลาขั้นต่ำ = บวก, ฟังจนจบ = บวกเพิ่ม, ข้ามเร็ว = ลบ
- คะแนนลดลงตามอายุ (half-life `TASTE_HALF_LIFE_DAYS`), เพลงโปรดได้ตัวคูณ
- ได้: คะแนนศิลปิน/เพลง, affinity 0..1, เพลงที่เพิ่งฟัง (cooldown), เพลงที่ไม่ชอบ

## การใช้
- `RadioSelector`: จัดอันดับใหม่ตาม affinity, ตัดเพลงที่เพิ่งฟัง/ไม่ชอบ
- `RadioEngine`: ทุก ๆ `TASTE_ARTIST_EVERY` เพลงสอดเพลงจากศิลปินที่ฟังบ่อย (หมุนเวียน ไม่ซ้ำ)
- `PlayerController.playForYou()` + หน้าค้นหา (ปุ่ม "เล่นเพลงที่คุณน่าจะชอบ", ชิปศิลปินที่ฟังบ่อย)

## ระบบอื่นที่ปรับพร้อมกัน
- ข้ามเพลงที่เล่นไม่ได้ในคิวแนะนำอัตโนมัติ (สูงสุด `MAX_CONSECUTIVE_AUTO_SKIPS` ครั้งติด)
- prefetch ลิงก์เสียงของเพลงถัดไปให้ต่อเพลงลื่นขึ้น
