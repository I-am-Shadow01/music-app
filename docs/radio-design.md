# Radio — เพลงถัดไปที่ไม่อิงผลค้นหา

## ปัญหาเดิม
กดเล่นเพลงจากผลค้นหา → `playQueue(results, index)` ทำให้ผลค้นหาทั้งลิสต์กลายเป็นคิว เพลงถัดไปจึงเป็นเพลง
อันดับถัดไปของคำค้น ซึ่งมักเป็นเพลงเดิมคนละคลิป (MV / Lyrics / Live / ช่อง cover) → ซ้ำซ้อน

## แนวคิดใหม่
กดเล่นจากผลค้นหา = เริ่ม **Radio** จากเพลงนั้น: คิวมีเพลงเดียว แล้วเติมเพลงแนะนำเรื่อยๆ ตามเพลงที่ฟัง
(เปิด/ปิดได้ที่ ตั้งค่า → การเล่น; ปิด = กลับเป็นพฤติกรรมเดิม) เพลงโปรด "เล่นทั้งหมด" ยังเล่นเป็นลิสต์ปกติ

```
PlayerController ──ขอเติมเมื่อรอเล่น < lowWatermark──▶ RadioEngine ──▶ RadioSource (YoutubeRadioSource)
                                                          │              1) YouTube Mix (RD{videoId}) แบ่งหน้า
                                                          │              2) related ของเพลงท้ายคิว
                                                          │              3) ค้นหาด้วยชื่อศิลปินท้ายคิว
                                                          ▼
                                                    RadioSelector (pure): กันซ้ำ + กรอง + กระจายศิลปิน
```

## กฎการคัดเพลง (`RadioSelector`)
1. ไม่ซ้ำ id กับที่อยู่ในคิว (รวมที่เล่นไปแล้ว)
2. ไม่ซ้ำ "เพลงเดียวกัน" แม้คนละคลิป — เทียบชื่อเพลงที่ตัด `(Official MV)`, `[Lyrics]`, `feat.`, ชื่อศิลปินนำหน้า, ส่วนท้าย `| ช่อง` แล้ว
   (ชื่อสั้น/ทั่วไปต้องศิลปินตรงกันด้วย กันชนมั่วอย่าง "Home")
3. ตัดคลิปที่ไม่ใช่เพลงทั่วไป: ไม่รู้ความยาว/สตรีมสด, สั้นหรือยาวเกินกำหนด, ชื่อเป็น full album / karaoke / reaction ฯลฯ
4. กระจายศิลปิน: ในหน้าต่างล่าสุดศิลปินเดียวกันไม่เกินโควตา (ถ้ามีแต่ศิลปินเดียวยังเติมให้ ไม่ปล่อยคิวว่าง)

ทุกค่าตัวเลข/รายการคำอยู่ใน `AppConstants` (กลุ่ม `RADIO_*`) และห่อเป็น `RadioConfig` ให้เทสต์ปรับได้

## พฤติกรรมที่ควรรู้
- เพลงที่ผู้ใช้กด "เพิ่มเข้าคิว" ใน Radio จะแทรกก่อนเพลงแนะนำ (ไม่ไปต่อท้ายสุดจนไม่ถึงคิว)
- สุ่ม (shuffle) ใน Radio สุ่มเฉพาะเพลงที่ยังไม่ได้เล่น
- ปลายคิว/เพลงจบตอนยังเติมไม่ทัน: รอเติมให้เสร็จก่อนเล่นต่อ; เติมไม่ได้เลย (ออฟไลน์) = หยุดตามปกติ แล้วรอ backoff ก่อนลองใหม่
- การเติมเบื้องหลังใช้ extractor ของตัวเอง ไม่แตะ search session ของ `MusicRepository`
